Typography

Two fonts are used throughout the app. DM Sans handles all English UI text. Noto Sans Malayalam is used exclusively for every Malayalam character — no exceptions.

Font Import
@import url('https://fonts.googleapis.com/css2?family=DM+Sans:wght@300;400;500;600;700&family=Noto+Sans+Malayalam:wght@400;500;600;700&family=Literata:ital,wght@0,400;0,500;0,600;1,400;1,500&display=swap'); /* DM Sans — all English UI text */ font-family: 'DM Sans', sans-serif; /* Noto Sans Malayalam — ALL Malayalam characters, every context */ font-family: 'Noto Sans Malayalam', sans-serif; /* Literata — ISO 15919 transliteration only, always in #C8922A */ font-family: 'Literata', Georgia, serif;
Rule: Noto Sans Malayalam applies to every Malayalam Unicode character — in cards, lesson screens, the writing canvas reference, the Phoneme Contrast Matrix, and ISO label pairings. Never use a system font for Malayalam characters.

04

Buttons

All buttons use pill shape (border-radius: 999px). No square buttons anywhere in the app. Five button variants cover all use cases.

Button Variants
Primary (orange): Main lesson actions — Check, Next, Start
Secondary (cream): Destructive-lite actions — Clear, Skip, Back
Teal: Positive completion — Continue, Done, Next Module
Ghost: Low-priority actions — Skip, Cancel
Disabled: When no input has been given (e.g. canvas is empty)
Answer Choice Buttons

Used in discrimination, identification, and transliteration tasks. Not pill-shaped — these use border-radius: 14px to feel distinct from action buttons.

Default: White bg, sand border
Selected: Cream bg, orange border — before answer is confirmed
Correct: Teal light bg, teal border — after correct selection
Wrong: Error light bg, error border — after incorrect selection

Animations

Animations are purposeful and brief. They communicate meaning — not decoration. Each animation has a specific job: celebrate progress, signal feedback, or make an abstract concept concrete.

Plays when a learner completes all lessons in a module and the next unlocks.

General Animation Principles
Keep it short: No animation exceeds 1.2s. Most are under 600ms.
Easing: Use ease for all animations. Never linear.
No animation stacking: Only one animation plays at a time. Don't chain celebration animations.
Haptics: Pair module unlock with success haptic. Pair incorrect with error haptic. Correct answer: light haptic.
Reduce motion: Respect prefers-reduced-motion — disable scale and translate animations, keep colour transitions.
@media (prefers-reduced-motion: reduce) { * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }

Module Header Illustrations

Each module card has a 200px-tall Kerala scene illustration as its header. Secular, culturally rooted, painted in the brand palette. Four illustrations are provided as ready-to-use SVG code below.

Illustration Style Rules
Dimensions: Full card width × 200px height
Format: Inline SVG — scalable, no network requests, no external assets
Palette: Brand colours only. No colours outside the defined palette.
Style: Flat illustration, no gradients inside shapes, no photorealism
Content: Secular scenes from Kerala nature and daily life — no religious imagery
Scenes assigned to modules: developer assigns based on module number cycling through available illustrations
Illustration 1 — Kerala Backwaters at Dusk

Coconut palms, still water, a small wooden boat, warm evening sky. Use for Module 1 or any vowel introduction module.

Illustration 2 — Kerala Spice Market

Piles of turmeric, chilli, pepper, cardamom and cinnamon on a market counter under a warm awning. Use for consonant modules.

Illustration 3 — Western Ghats Rainforest with Coconut Palms

Layered jungle canopy, coconut palms rising above the treeline, mist, ferns, hornbill silhouette. Use for chillu or cluster modules.

Illustration 4 — Lotus Lake with Peacock

Still water, lotus pads, pink flowers, a peacock on the bank with fanned tail. Use for review or milestone modules.
